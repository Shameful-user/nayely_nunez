# Portafolio de Nayely Núñez

Portafolio estático construido con HTML, CSS y JavaScript, compatible con GitHub Pages. No requiere instalación, backend ni dependencias externas.

## Contenido

- `index.html`: presentación y proyectos destacados.
- `proyectos/`: casos de estudio de análisis de ventas, Bite & Balance y Laura Leal.
- `css/` y `js/`: estilos responsive, menú móvil y lightbox accesible.
- `assets/images/`: imágenes y capturas reales optimizadas.
- `assets/icons/`: favicon e iconos locales, con sus fuentes y licencias.
- `assets/downloads/dashboard-analisis-ventas.pbix`: archivo descargable para Power BI Desktop.

## Uso y publicación

Abre `index.html` en el navegador. Para GitHub Pages, selecciona la rama publicada y la carpeta raíz en Settings → Pages. Las rutas relativas permiten publicar bajo la URL de un repositorio.

`.gitignore` mantiene fuera del repositorio los archivos internos, documentación de trabajo, herramientas, pruebas y originales locales. `_config.yml` excluye ese material del build estándar de Pages; los workflows personalizados deben publicar únicamente los archivos de producción.

Las obras de Laura Leal y el contenido artístico mostrado pertenecen a la artista y a sus respectivos titulares. El caso de estudio describe el trabajo de organización, implementación y optimización web realizado sobre su sitio.
